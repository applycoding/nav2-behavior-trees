# nav2-behavior-trees

Simulation only. A BehaviorTree.CPP v4 mission tree for a cleaning robot that undocks, covers zones lane by lane, recovers from blockages, docks on low battery and resumes, tested headless in a deterministic grid world with an optional ROS 2 Humble and Nav2 layer. See PLAN.md.
